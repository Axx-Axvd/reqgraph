# Бриф: «Гараж 61»

Небольшой автосервис, 4 мастера. Клиенты записываются только по телефону, администратор весь день отвечает на звонки, а около 15% записей пропадают из-за неявок. Нужна онлайн-запись с напоминаниями. Есть три корпоративных клиента с автопарками, они работают по договору с отсрочкой оплаты, их заказы сейчас ведутся в тетради.

*Пример условный: компания, люди и цифры вымышлены.*
