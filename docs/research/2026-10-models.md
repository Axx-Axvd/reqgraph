# Модели и бесплатные тарифы — октябрь 2026

Дата проверки: **2026-10-21**. Источники — живые API из облачной VM, ключи подставляют network secrets:
- OpenRouter: `GET /api/v1/models` (468 моделей; цены, контекст и `supported_parameters`) и `GET /api/v1/key` (лимиты аккаунта);
- Groq: `GET /openai/v1/models` и заголовки `x-ratelimit-*` ответа;
- Google AI Studio: `GET /v1beta/openai/models`;
- для каждой рабочей модели — пробный вызов chat с `response_format={"type":"json_object"}`.

Тарифы Supabase, Render и Vercel взяты с их официальных страниц. Cerebras исключён (решение автора).

Обозначения: **tools** — tool calling; **SO** — `structured_outputs` (JSON Schema); **RF** — `response_format` (JSON mode). Цены — $ за 1 млн токенов, вход / выход, по OpenRouter.

## Что это меняет

1. **`roles.yaml` в 06_models** нужно переписать по таблице «Кандидаты по ролям» — в T-005. Это не меняет ADR-011, только данные.
2. **Groq TPM 8000** исключает Groq для Analyst и Modeler: их промпт с транскриптом больше 8000 токенов. На Groq остаются Interviewer, Reviewer и симулятор в dev. Роутер (T-005) должен оценивать длину промпта и сразу идти к следующему провайдеру, а не ловить 429.
3. **OpenRouter 50 RPD** — один прогон с интервью (80–100 вызовов) на `:free` за день **не помещается**. Профиль `free` годится только для коротких smoke-тестов. Разработка агентов в S2 идёт либо на Groq и Gemini, либо на $10 кредитов (это повышает дневной лимит; порог проверить в документации). Это решение автора: см. вопросы в preflight-report.
4. **Probe (T-006)** запускать с `--repeat 3` на моделях из таблицы выше; `openrouter/free` в probe не включать.
5. **Supabase: ровно 2 активных проекта** — staging и prod. Для экспериментов отдельный проект не заводить: локальный стек или FileStore.
