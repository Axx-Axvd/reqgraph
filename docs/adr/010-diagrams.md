# ADR-010: bpmn-js в браузере и Kroki для остальных нотаций

- Статус: принято
- Дата: 2026-10-20
- Источник: docs/tech-design/README.md, таблица «Ключевые решения»

## Решение

Диаграммы: bpmn-js в браузере, Kroki для SVG остальных нотаций.

## Почему

не тащим Java и Graphviz в контейнер.

## Рассмотренные альтернативы

- рендер PlantUML и Graphviz в своём контейнере — Java и Graphviz не влезают в 512 МБ

## Последствия

Зависимость от kroki.io или своего контейнера Kroki; офлайн проверки SCH-004/005 пропускаются с уровнем info.
