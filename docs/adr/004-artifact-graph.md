# ADR-004: ArtifactGraph как единый источник правды, изменения только патчами

- Статус: принято
- Дата: 2026-10-20
- Источник: docs/tech-design/README.md, таблица «Ключевые решения»

## Решение

Единый источник правды — ArtifactGraph (Pydantic); агенты возвращают патчи, а не текст.

## Почему

детерминированные id, атомарные правки, понятный diff.

## Рассмотренные альтернативы

- агенты пишут Markdown-документы напрямую — нельзя проверить связи
- агент возвращает граф целиком — дорого по токенам и легко потерять чужие узлы

## Последствия

Id выдаёт код (IdAllocator), каждое изменение атомарно и видно в diff; агенту разрешены только свои типы узлов.
