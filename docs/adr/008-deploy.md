# ADR-008: Деплой: Vercel для web, Render для api и worker, docker compose локально

- Статус: принято
- Дата: 2026-10-20
- Источник: docs/tech-design/README.md, таблица «Ключевые решения»

## Решение

Деплой: Vercel (web) + Render free (api + worker); локально docker compose.

## Почему

$0; для защиты в РФ — офлайн-стенд без зависимостей.

## Рассмотренные альтернативы

- Fly.io / Railway — платные, запасной вариант
- Google Cloud Run — нужна карта, оплата из РФ невозможна
- HF Spaces Docker — нужна подписка PRO

## Последствия

$0 в месяц; Render засыпает через 15 минут и даёт 512 МБ памяти; для защиты в РФ используется офлайн-стенд.
