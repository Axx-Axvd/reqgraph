# ADR-014: Soundness через pm4py с переводчиком DSL

- Статус: принято (2026-10-21, решение автора)
- Дата: 2026-10-21
- Уточняет: [ADR-005](005-process-dsl.md), [ADR-006](006-deterministic-checks.md); реализация SND-002 из 05_ci.md
- Источник: [docs/research/2026-10-versions.md](../research/2026-10-versions.md)

## Контекст

SND-002 («процесс sound»: из любого состояния можно дойти до конца, нет зависаний и мёртвых задач) по 05_ci.md делается через pm4py: BPMN → сеть Петри → `check_soundness`. Проверка 21.10.2026:

1. pm4py 2.7.23 — лицензия **AGPL-3.0-or-later**.
2. Импорт +160 МБ RSS, 5,6 с (pandas, scipy, matplotlib, cvxopt, graphviz).
3. Конвертер BPMN → сеть Петри понимает только задачи, старт/конец и шлюзы xor/and/or. **Событийный шлюз и промежуточные события (таймер, сообщение) пропускает**, а они есть в DSL v1 и в PRC-02 эталона.

## Решение

- Оставляем pm4py: своя сеть Петри и перебор состояний не пишутся.
- Перед проверкой `dsl/soundness.py` (~20 строк) строит «вид для soundness»: `event_based` → `xor`, `timer` и `message` → задача. Для soundness это эквивалентно: событийный шлюз — это отложенный выбор, в сети Петри он выглядит как место с несколькими выходами, ровно как xor.
- pm4py импортируется лениво (внутри SND-002), чтобы CLI и остальные проверки стартовали быстро.
- Лицензия: наш код остаётся под MIT; поставка с pm4py подчиняется AGPL. Репозиторий и демо публичные, исходники открыты — требование AGPL выполняется. В README — раздел «Лицензии зависимостей».

## Последствия

- T-106 (проверки схем и soundness) — меньше кода; golden-тесты на 5 процессах, включая PRC-02 с событийным шлюзом.
- Память: на Render Free (512 МБ, ADR-008) pm4py импортируется лениво и только в SND-002; если воркеру не хватит памяти — план Б из 07_deploy: SND-002 отдельным фоновым шагом или Railway/Fly (~$5).
- Если когда-нибудь понадобится закрытая коммерческая версия — pm4py придётся заменить (или купить коммерческую лицензию). Для диплома и пет-проекта это не нужно.

## Альтернативы

- Своя проверка soundness на сети Петри (~150–200 строк) — чище по лицензии и памяти, но больше кода; отклонено автором.
