# ADR-012: Тексты стандартов в репозиторий не кладутся

- Статус: принято
- Дата: 2026-10-20
- Источник: docs/tech-design/README.md, таблица «Ключевые решения»

## Решение

Тексты стандартов в репозиторий не кладём — только свои чек-листы и структуры разделов.

## Почему

авторское право ISO; ГОСТ — ссылками.

## Рассмотренные альтернативы

- положить тексты ISO и ГОСТ для RAG — нарушение авторских прав, репозиторий публичный

## Последствия

В standards/*.yaml только свои формулировки правил и названия разделов; соответствие разделов ГОСТ сверяется вручную.
