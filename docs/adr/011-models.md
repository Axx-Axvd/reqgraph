# ADR-011: Open-weight модели по ролям, выбор по своему мини-бенчмарку

- Статус: принято
- Дата: 2026-10-20
- Источник: docs/tech-design/README.md, таблица «Ключевые решения»

## Решение

Модели: open-weight по ролям, выбор по своему мини-бенчмарку; один и тот же LLM для всех методов в эксперименте.

## Почему

дёшево и честно: сравниваем методы, а не модели.

## Рассмотренные альтернативы

- одна frontier-модель для всего — дорого (~$2.5-4 за прогон)
- разные модели для разных методов в эксперименте — сравнение становится нечестным

## Последствия

Нужен probe-бенчмарк и его повтор перед экспериментами; roles.yaml замораживается на время S6.
