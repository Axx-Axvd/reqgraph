# ADR-003: Тонкий роутер моделей над openai SDK и instructor

- Статус: принято; реализация уточнена [ADR-013](013-llm-layer-pydantic-ai.md) — pydantic-ai вместо openai SDK + instructor
- Дата: 2026-10-20
- Источник: docs/tech-design/README.md, таблица «Ключевые решения»

## Решение

LLM через тонкий роутер над openai SDK + instructor; без LangChain-обёрток.

## Почему

все провайдеры OpenAI-совместимы; меньше памяти на бесплатном хостинге.

## Рассмотренные альтернативы

- LangChain chat models — тяжелее и лишний слой абстракций
- LiteLLM SDK — удобен, но заметно больше по памяти и зависимостям

## Последствия

Любой OpenAI-совместимый провайдер подключается строкой в roles.yaml; фолбэки, бюджет и учёт стоимости пишем сами (~200 строк).
