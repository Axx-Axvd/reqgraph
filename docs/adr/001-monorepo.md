# ADR-001: Монорепозиторий с открытой лицензией MIT

- Статус: принято
- Дата: 2026-10-20
- Источник: docs/tech-design/README.md, таблица «Ключевые решения»

## Решение

Монорепо: Python-ядро (uv) + Next.js (pnpm), MIT, публичный с первого дня.

## Почему

одна история коммитов для диплома и CV; Claude Code видит весь контекст.

## Рассмотренные альтернативы

- два репозитория (ядро и веб) — сложнее синхронизировать схемы и историю для диплома
- закрытый репозиторий до защиты — теряется ценность для CV и приоритет идеи

## Последствия

Одна история коммитов; JSON Schema из ядра напрямую используется фронтендом; всё публично с первого дня — нельзя коммитить секреты.
