# ADR-006: Детерминированные проверки без LLM

- Статус: принято
- Дата: 2026-10-20
- Источник: docs/tech-design/README.md, таблица «Ключевые решения»

## Решение

Проверки не вызывают LLM (кроме опц. ISO-002).

## Почему

воспроизводимость и честная метрика качества.

## Рассмотренные альтернативы

- LLM-as-judge для всех проверок — дёшево в разработке, но невоспроизводимо и завышает оценки

## Последствия

Одинаковый граф всегда даёт одинаковый отчёт; метрики эксперимента честные; опциональный судья ISO-002 считается отдельно.
