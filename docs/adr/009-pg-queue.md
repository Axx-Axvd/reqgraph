# ADR-009: Очередь фоновых задач в Postgres (SKIP LOCKED)

- Статус: принято
- Дата: 2026-10-20
- Источник: docs/tech-design/README.md, таблица «Ключевые решения»

## Решение

Фоновые задачи: очередь в Postgres (SKIP LOCKED), без Redis.

## Почему

один сервис на бесплатном тарифе, меньше движущихся частей.

## Рассмотренные альтернативы

- Celery + Redis — ещё один сервис
- arq — нужен Redis
- Supabase Edge Functions — Deno/TypeScript и лимит времени выполнения

## Последствия

Api и worker живут в одном процессе на бесплатном тарифе; масштабирование ограничено, для демо достаточно.
