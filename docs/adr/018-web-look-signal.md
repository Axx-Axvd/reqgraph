# ADR-018: Внешний вид сайта — Tailwind и shadcn/ui, стиль «Сигнал»

- Статус: принято (2026-11-23, решение автора по макету)
- Дата: 2026-11-23
- Уточняет: стек фронтенда из [02_arch.md](../tech-design/02_arch.md) (было: свой CSS)
- Источник: эпик E5b в [backlog](../backlog.md), задачи T-508…T-512

## Контекст

После T-504 и T-505 сайт работает, но выглядит как учебная работа: свой CSS без системы, разные отступы и кнопки на каждой странице, нет тёмной темы, плохо на телефоне. Первый прогон на prod (22.11) показал и вторую проблему: интервью тяжело для человека без ИТ, и интерфейс это не смягчает.

22–23.11 стиль выбирался на макете (холст автора «reqgraph — дизайн продукта»): три направления → итерация «Сигнал» → 13 экранов в двух темах, сквозной кликабельный прототип, лист компонентов. Макет проверен как продукт: ширины 1440–320 px, сценарии «сломать», axe в обеих темах; найдено и исправлено 14 дефектов (journal, 23.11).

## Решение

- Оформление — Tailwind CSS; доступные компоненты (диалоги, меню, переключатели) — shadcn/ui на Radix, код компонентов копируется в репозиторий; иконки — `lucide-react`; шрифты — пакетами `@fontsource`, встроены в сайт (уточнено 23.11 в T-508: `next/font/google` скачивает шрифты при сборке, а офлайн-стенд T-507 собирается без сети).
- Стиль «Сигнал» задаётся токенами (CSS-переменные) со светлым и тёмным режимом. Тёмная тема «сумерки»: фон `#1E2133`, панели `#262A40`/`#2F344D`; смысловые цвета: коралл `#FF6A3D` — человек и действие, мята `#6EDCB4` — проверено, янтарь `#E9C46A` — пробел. Шрифты: Unbounded — заголовки, Onest — интерфейс и чат, PT Serif — лист ТЗ.
- Правила: одна коралловая кнопка на экран; помощник — «аналитик»; номера требований человеку не показываются; кнопки на телефоне ≥ 44 px; видимый фокус; `prefers-reduced-motion`.
- Образец для каждой задачи — доска макета; проверки — e2e с теми же сценариями, что прошёл макет (T-512).

## Альтернативы

- Оставить свой CSS и доработать — дешевле сейчас, но без системы токенов и готовых доступных компонентов каждая страница снова разойдётся; тёмную тему пришлось бы писать вручную.
- Направления первой итерации макета («Ясность», «Разговор», «Граф») — отвергнуты автором как стерильные.
- Шрифты «три голоса» (антиква для слов заказчика, гротеск для интерфейса, моноширинный для машины) — отвергнуты автором: разные шрифты в чате мешают.
- Анимации-«вау» на главной и входе — отвергнуты и откачены; оставлены спокойные, объясняющие продукт.

## Последствия

- Новые зависимости только у сайта (Vercel): `tailwindcss`, `@tailwindcss/postcss`, `lucide-react`, `class-variance-authority`, `clsx`, `tailwind-merge`, `tw-animate-css`, `@radix-ui/*` по мере нужды; dev — `@axe-core/playwright`. Сервер на Render (512 МБ) не затронут.
- Меняются: T-508…T-512 (E5b), таблица компонентов в 02_arch.md. Возможности с макета, которым нужен сервер, вынесены в T-513, T-514, T-515.
- Откат: стили живут в `apps/web`, ядро и API от них не зависят; вернуть прежний CSS — откат PR задач E5b.
