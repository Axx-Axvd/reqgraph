# ADR-005: LLM пишет JSON DSL процесса, BPMN XML генерирует компилятор

- Статус: принято
- Дата: 2026-10-20
- Источник: docs/tech-design/README.md, таблица «Ключевые решения»

## Решение

Процессы: LLM пишет JSON DSL, BPMN XML генерирует компилятор.

## Почему

LLM плохо пишут валидный BPMN XML (BEF4LLM); компилятор даёт 100% схемы.

## Рассмотренные альтернативы

- LLM пишет BPMN 2.0 XML напрямую — по BEF4LLM валидный XML остаётся слабым местом моделей
- Mermaid flowchart вместо BPMN — не стандарт, нет soundness-проверки через сеть Петри

## Последствия

Схема BPMN валидна по построению; ошибки логики (soundness) возвращаются Modeler с id узла; нужен свой компилятор и раскладка DI.
