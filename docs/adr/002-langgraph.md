# ADR-002: Оркестрация агентов на LangGraph

- Статус: принято
- Дата: 2026-10-20
- Источник: docs/tech-design/README.md, таблица «Ключевые решения»

## Решение

Оркестрация на LangGraph (StateGraph, interrupt, Postgres-чекпоинтер).

## Почему

паузы интервью, возобновление после сна сервера, граф виден в коде.

## Рассмотренные альтернативы

- свой цикл на asyncio — придётся писать паузы, чекпоинты и возобновление самим
- CrewAI / AutoGen — меньше контроля над переходами и состоянием
- PydanticAI Graph — меньше готовой инфраструктуры чекпоинтов в Postgres

## Последствия

Интервью ставится на паузу через interrupt() и переживает перезапуск сервера; граф переходов описан в коде и проверяется тестами.
