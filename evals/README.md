# evals — оценка reqgraph

Входной слой проекта: зависит от `reqgraph`, сам `reqgraph` отсюда ничего не импортирует.

## Probe — мини-экзамен для моделей (T-006)

20 заданий в 4 блоках по 5 (`probe/cases.yaml`): извлечь требования из фрагмента интервью, описать процесс графом, переписать требование по ISO 29148, задать уточняющий вопрос. Оценки детерминированные, без LLM (`reqgraph_evals/scoring.py`); LLM-судья для переписанных требований — только с флагом `--judge`, отдельной колонкой.

```bash
uv run reqgraph-evals probe --models groq/openai/gpt-oss-120b,gemini/gemini-3.5-flash-lite --repeat 3
uv run reqgraph-evals rescore evals/reports/probe-YYYY-MM-DD.csv   # пересчёт оценок по сохранённым ответам
```

Отчёт: `reports/probe-YYYY-MM-DD[-tag].csv` — строка на задачу и повтор (модель, провайдер, температура, seed, хэш промпта, версия пакета, токены, $ факт и по прайсу, латентность, оценки, ответ модели) и `.md` со сводкой. Числа в документах — только из этих CSV.

Ограничения: сопоставление требований с эталоном — по основам слов (5 первых букв), проверки процесса и размытых слов временные — до настоящих проверок SCH/SND (T-106) и ISO (T-107); probe повторяется с ними в T-601. Задания не пересекаются с 15 сценариями диплома (T-303).
