Правила:
- узлы: ровно один start, хотя бы один end, задачи (task) и развилки (xor);
- id узлов — короткие латинские идентификаторы (start, t1, g1, end1 …), name — по-русски, задача начинается с глагола;
- у каждой развилки xor не меньше двух исходящих переходов, у переходов из развилки есть condition;
- каждый узел достижим из start, и из каждого узла можно дойти до end.
