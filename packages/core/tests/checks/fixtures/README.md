# Фикстуры проверок

- **good** — эталон `examples/garage61`: на нём все проверки молчат (ни ошибок, ни предупреждений).
- **bad** — `bad/mutations.yaml`: каждая мутация портит копию эталона (замена текста в одном файле
  или новый файл) и перечисляет проверки, которые обязаны сработать, и их узлы. Мутации из таблицы
  «Ожидаемые мутации» в `examples/garage61/REVIEW.md` помечены `review: true`.
- `bad/processes/*.process.json` — процессы с логическими ошибками для SND-*; мутации добавляют их
  в копию эталона.
